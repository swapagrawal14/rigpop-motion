# Brand assets

| File | Use |
|---|---|
| `docs/banner.png` (1600×440) | README hero + GitHub social preview |
| `docs/logo.png` (512×512) | avatar / app icon |
| `docs/logo.svg` (512×512) | vector source, scales anywhere |

Everything is generated from code and real artwork in this repo:

```bash
node docs/brand/build-brand.mjs
```

**Palette** — ink `#14110f` · cream `#f6f1e6` · yellow `#ffd94a` · coral `#e8695f` · plum `#3a3350`.

**Setting the GitHub social preview:** repo → Settings → *Social preview* → upload `docs/banner.png`.

Characters used in the banner: `characters/kabir-side/poses/pose_2.png` and
`characters/street-cat/cat_walk_cut.png` — so the branding is literally made with the engine.
